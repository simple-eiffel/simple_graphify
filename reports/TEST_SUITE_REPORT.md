## Defects found and fixed during verification

1. **ECF scan produced nothing** — `next_tag` terminated on the `<?xml` prolog
   instead of skipping non-element tags. Fixed: prolog/comment/closing tags
   are skipped; scan continues.
2. **Empty descriptions / zero contract metrics** — the Gobo bridge in
   simple_eiffel_parser (shallow preparse mode) does not populate
   header_comment/precondition/postcondition. Fixed: descriptions fall back to
   the source `note description:` clause; contract metrics fall back to
   require/ensure keyword-line counts; added has_invariant metric.
3. **Vacuous tests** — original tests used `check` instructions (with
   side-effecting fixture builds inside them), which are no-ops when check
   assertions are stripped in finalized code. Fixed: all tests now use
   TEST_SET_BASE `assert` (raises unconditionally) and side effects moved out
   of assertion expressions.
